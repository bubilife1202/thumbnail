# 썸네일 생성기

인스타그램, 유튜브, 쇼츠, 틱톡을 위한 썸네일을 쉽게 만들 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 지원 플랫폼
- **유튜브** (1280 x 720 px)
- **유튜브 쇼츠** (1080 x 1920 px)
- **인스타그램 포스트** (1080 x 1080 px)
- **인스타그램 스토리** (1080 x 1920 px)
- **틱톡** (1080 x 1920 px)

### 기능

#### 템플릿 시스템
- **6가지 미리 만들어진 템플릿**
  - 빈 캔버스: 처음부터 시작
  - 모던: 세련된 퍼플 그라데이션
  - 비브런트: 생동감 넘치는 핑크-오렌지
  - 미니멀: 깔끔한 그레이 톤
  - 다크: 세련된 다크 모드
  - 선셋: 따뜻한 오렌지-레드
- 원클릭 템플릿 적용으로 빠른 시작

#### 기존 이미지 사용
- **베이스 이미지 업로드**
  - 기존 썸네일이나 사진 위에 작업 가능
  - 이미지는 캔버스에 자동으로 맞춤
  - 언제든지 제거 가능

#### 배경 설정
- **3가지 배경 타입**
  - 단색 배경
  - 그라데이션 배경
  - 이미지 배경 업로드

#### 텍스트 추가
- 메인 텍스트 및 서브 텍스트
- 텍스트 색상 커스터마이징
- 폰트 크기 조절 (20px ~ 150px)
- 텍스트 그림자 효과

#### 오버레이 이미지
- **여러 이미지 추가 가능**
  - 로고, 아이콘, 스티커 등
  - 크기 조절 (50px ~ 500px)
  - 5가지 위치 옵션:
    - 오른쪽 상단
    - 왼쪽 상단
    - 오른쪽 하단
    - 왼쪽 하단
    - 중앙
  - 여러 이미지 동시 업로드 지원

#### 추가 요소
- 테두리 옵션
- 실시간 미리보기

#### 다운로드
- PNG 형식으로 다운로드
- 플랫폼별 최적화된 크기
- 자동 파일명 생성

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 원하는 플랫폼을 선택합니다
3. 배경, 텍스트, 추가 요소를 설정합니다
4. 실시간으로 미리보기를 확인합니다
5. '다운로드' 버튼을 클릭하여 썸네일을 저장합니다

## 기술 스택

- HTML5
- CSS3
- JavaScript (Canvas API)
- 순수 바닐라 자바스크립트 (프레임워크 없음)
