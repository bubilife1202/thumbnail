# 🎨 프로 썸네일 메이커

유튜브, 인스타그램, 틱톡, 쇼츠를 위한 전문가급 썸네일 생성 도구

> Made with ❤️ by [Reelscode](https://reelscode.com)

## ✨ 주요 기능

### 🎯 플랫폼 지원
- **유튜브** (1280 x 720 px)
- **유튜브 쇼츠** (1080 x 1920 px)
- **인스타그램 포스트** (1080 x 1080 px)
- **인스타그램 스토리** (1080 x 1920 px)
- **틱톡** (1080 x 1920 px)

### 🎨 프로페셔널 템플릿
8가지 미리 제작된 템플릿으로 빠른 시작:
- **빈 캔버스** - 처음부터 제작
- **MrBeast 스타일** - 강렬한 빨강-주황 그라데이션 + 굵은 텍스트
- **모던** - 세련된 보라색 그라데이션
- **비브런트** - 생동감 넘치는 핑크-오렌지
- **미니멀** - 깔끔한 그레이 톤
- **다크** - 세련된 다크 모드
- **네온** - 사이버펑크 네온 효과
- **선셋** - 따뜻한 오렌지-레드

### 📝 고급 텍스트 기능
- **무제한 텍스트 레이어** 추가
- **9가지 폰트 선택**:
  - 한글: 본고딕, 검은고딕, 주아체, 나눔고딕, 도현체
  - 영문: Anton, Bebas Neue, Righteous, Staatliches
- **5가지 스타일 프리셋**:
  - 기본
  - 아웃라인 (두꺼운 테두리)
  - 그림자
  - 네온 글로우
  - 배경 박스 (반투명)
- **세밀한 조정**:
  - 폰트 크기 (20-200px)
  - 텍스트 색상
  - 테두리 두께 및 색상
  - 그림자 크기 및 색상
  - 배경 박스 색상 및 투명도
- **드래그 앤 드롭**으로 자유로운 위치 조정

### 🖼️ 이미지 & 스티커
- **다중 이미지 업로드**
- **이미지 편집**:
  - 크기 조절 (50-800px)
  - 회전 (0-360°)
  - 투명도 조절
  - 드래그로 위치 이동
- **16가지 스티커/이모지**:
  - ⭐ 🔥 💯 ✨ 👍 ❤️ 😱 😍 🎉 🚀 💰 ⚡ 🎯 💎 👀 🔔

### 🔷 도형 추가
- **4가지 도형**:
  - 사각형
  - 원
  - 삼각형
  - 화살표
- **완전한 커스터마이징**:
  - 채우기 색상
  - 테두리 색상 및 두께
  - 크기 및 회전

### 🎭 이미지 효과 & 필터
- **필터 조정**:
  - 밝기 (0-200%)
  - 대비 (0-200%)
  - 채도 (0-200%)
  - 블러 (0-20px)
- **6가지 필터 프리셋**:
  - 없음 (원본)
  - 빈티지
  - 흑백
  - 따뜻하게
  - 차갑게
  - 고대비

### 🎯 레이어 시스템
- **완전한 레이어 관리**:
  - 무제한 레이어 추가
  - 드래그로 순서 변경
  - 각 레이어 표시/숨김
  - 선택된 레이어 강조 표시
  - 레이어별 아이콘 및 이름
- **레이어 타입**: 텍스트, 이미지, 이모지, 도형

### ⏮️ 히스토리 (실행 취소/다시 실행)
- **최대 50단계** 히스토리 저장
- **키보드 단축키**:
  - Ctrl/Cmd + Z: 실행 취소
  - Ctrl/Cmd + Y 또는 Ctrl/Cmd + Shift + Z: 다시 실행
- 모든 변경사항 자동 저장

### ⌨️ 키보드 단축키
- **Ctrl/Cmd + Z**: 실행 취소
- **Ctrl/Cmd + Y**: 다시 실행
- **Ctrl/Cmd + S**: 다운로드
- **Delete**: 선택된 레이어 삭제

### 💾 프리셋 저장/불러오기
- **로컬 스토리지** 활용
- 자주 사용하는 디자인을 프리셋으로 저장
- 저장된 프리셋 불러와서 재사용
- 무제한 프리셋 저장 가능

### 🎨 배경 옵션
- **베이스 이미지**: 기존 이미지 위에 작업
- **단색 배경**
- **그라데이션 배경**
- **테두리 옵션**

### 📥 내보내기
- **PNG 형식** 다운로드
- 플랫폼별 최적화된 크기
- 자동 파일명 생성 (플랫폼명_타임스탬프.png)
- 고화질 출력

## 🚀 사용 방법

### 빠른 시작
1. **플랫폼 선택** - 상단 툴바에서 원하는 플랫폼 클릭
2. **템플릿 선택** - 8가지 템플릿 중 하나 선택 (또는 빈 캔버스)
3. **요소 추가**:
   - 텍스트: "텍스트" 탭 → "텍스트 레이어 추가"
   - 이미지: "이미지" 탭 → "이미지 업로드" 또는 스티커 클릭
   - 도형: "도형" 탭 → 원하는 도형 클릭
4. **편집**:
   - 캔버스에서 요소 드래그로 위치 이동
   - 왼쪽 패널에서 세부 조정
   - 오른쪽 레이어 패널에서 레이어 관리
5. **효과 적용** - "효과" 탭에서 필터 및 배경 설정
6. **다운로드** - 상단 "📥 다운로드" 버튼 클릭

### 고급 워크플로우
1. **베이스 이미지 업로드** (선택사항)
2. **텍스트 레이어 추가 및 스타일링**
   - 폰트 선택
   - 스타일 프리셋 적용 (아웃라인, 그림자, 네온 등)
   - 세밀한 조정 (테두리, 그림자, 배경 박스)
3. **이미지/스티커 추가**
   - 로고, 아이콘, 이모지 추가
   - 크기 및 회전 조절
4. **도형으로 강조**
   - 화살표, 원 등으로 주목도 향상
5. **필터로 분위기 연출**
6. **프리셋 저장** (재사용을 위해)
7. **다운로드**

## 🎯 실전 팁

### 유튜브 썸네일
- **MrBeast 스타일 템플릿** 추천
- **큰 텍스트** (100px 이상)
- **강렬한 아웃라인** (10-15px 검정 테두리)
- **강조 요소** (화살표, 원으로 강조)
- **고대비 색상** 사용

### 인스타그램
- **미니멀 또는 모던 템플릿** 추천
- **적당한 텍스트 크기** (70-90px)
- **깔끔한 레이아웃**
- **세련된 색상 조합**

### 쇼츠/릴스/틱톡
- **수직 레이아웃** 고려
- **위/중/아래** 구성
- **큰 텍스트** + **명확한 메시지**
- **네온 효과**로 시선 집중

## 🛠️ 기술 스택

- **HTML5 Canvas** - 고성능 렌더링
- **순수 JavaScript** (프레임워크 없음)
- **Google Fonts** 통합
- **모던 CSS3** - 다크 테마
- **로컬 스토리지** - 프리셋 저장

## 💡 특징

### 직관적인 UI/UX
- **3패널 레이아웃**: 컨트롤 | 캔버스 | 레이어
- **탭 기반 인터페이스**: 기능별 정리
- **실시간 미리보기**: 즉각적인 피드백
- **다크 테마**: 눈의 피로 감소

### 프로페셔널 워크플로우
- **레이어 시스템**: Photoshop 스타일
- **히스토리 관리**: 실수 걱정 없음
- **드래그 앤 드롭**: 직관적인 편집
- **키보드 단축키**: 빠른 작업

### 성능 최적화
- **경량**: 외부 라이브러리 없음
- **빠른 로딩**: ~80KB 총 크기
- **부드러운 렌더링**: 최적화된 Canvas 사용
- **로컬 처리**: 서버 업로드 불필요
