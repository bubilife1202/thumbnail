# 썸네일 생성기

인스타그램, 유튜브, 쇼츠, 틱톡을 위한 썸네일을 쉽게 만들 수 있는 웹 애플리케이션입니다.

## 주요 기능

### 지원 플랫폼
- **유튜브** (1280 x 720 px)
- **유튜브 쇼츠** (1080 x 1920 px)
- **인스타그램 포스트** (1080 x 1080 px)
- **인스타그램 스토리** (1080 x 1920 px)
- **틱톡** (1080 x 1920 px)

### 기능
- **배경 설정**
  - 단색 배경
  - 그라데이션 배경
  - 이미지 배경 업로드

- **텍스트 추가**
  - 메인 텍스트 및 서브 텍스트
  - 텍스트 색상 커스터마이징
  - 폰트 크기 조절 (20px ~ 150px)
  - 텍스트 그림자 효과

- **추가 요소**
  - 로고/이미지 추가
  - 테두리 옵션

- **다운로드**
  - PNG 형식으로 다운로드
  - 플랫폼별 최적화된 크기

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 원하는 플랫폼을 선택합니다
3. 배경, 텍스트, 추가 요소를 설정합니다
4. 실시간으로 미리보기를 확인합니다
5. '다운로드' 버튼을 클릭하여 썸네일을 저장합니다

## 기술 스택

- HTML5
- CSS3
- JavaScript (Canvas API)
- 순수 바닐라 자바스크립트 (프레임워크 없음)

## 특징

- 반응형 디자인
- 실시간 미리보기
- 사용하기 쉬운 인터페이스
- 별도의 설치 불필요 (웹 브라우저만 있으면 됨)
